# 25 — Auditoría de frontend, backend, CI y seguridad (2026-11-08)

Auditoría interna completa pedida por Diego el 2026-11-08, hecha con tres vías en paralelo: revisión de seguridad del backend y la CI (OWASP/STRIDE, con intento de explotación sobre el código), revisión del frontend (accesibilidad WCAG 2.2 AA, SEO, rendimiento, corrección) y rediseño del acceso al panel ([ADR-024](./21-decisions.md)). No hubo hallazgos críticos; el historial de git no contiene secretos; `npm audit` sin vulnerabilidades.

Alcance: `src/**`, `functions/**`, `public/_headers`, `vercel.json`, `.github/workflows/*`, `package.json`/lockfile, `docs/*`, `tests/*`. Fuera de alcance: la cuenta de Cloudflare y GitHub (no hay despliegue todavía), WhatsApp/Meta.
